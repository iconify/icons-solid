Browse all icons: [preview Streamline color on Iconify](https://icon-sets.iconify.design/streamline-color/)

## Installation

```bash
npm install github:iconify/icons-solid#streamline-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/streamline-color/graph';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/streamline-color/pie-chart-flat';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
