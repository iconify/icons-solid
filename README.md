Browse all icons: [preview Lucide Extended on Iconify](https://icon-sets.iconify.design/lucide-extended/)

## Installation

```bash
npm install gitlab:iconify-icons/solid#lucide-extended
```

or
```bash
npm install github:iconify/icons-solid#lucide-extended
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/lucide-extended/circle-check-filled';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/lucide-extended/award-duotone';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/lucide-extended/house-filled';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
