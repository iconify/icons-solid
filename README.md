Browse all icons: **[Preview Glyphs Poly](https://icon-sets.iconify.design/glyphs-poly/)**

## Installation

```bash
npm install github:iconify/icons-solid#glyphs-poly
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/glyphs-poly/mouse-2';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/glyphs-poly/object-select';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
