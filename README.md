Browse all icons: **[Preview Carbon](https://icon-sets.iconify.design/carbon/)**

## Installation

```bash
npm install github:iconify/icons-solid#carbon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/carbon/user-certification';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/carbon/humidity';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/carbon/edit-off';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
