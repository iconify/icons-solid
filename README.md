Browse all icons: [preview Mono Icons on Iconify](https://icon-sets.iconify.design/mono-icons/)

## Installation

```bash
npm install github:iconify/icons-solid#mono-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/mono-icons/user';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/mono-icons/log-in';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/mono-icons/play';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
