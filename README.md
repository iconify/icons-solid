**Flag Icons**

License: [MIT](https://github.com/lipis/flag-icons/blob/main/LICENSE)

Browse all icons: [preview Flag Icons on Iconify](https://icon-sets.iconify.design/flag/)

## Installation

```bash
npm install gitlab:iconify-icons/solid#flag
```

or
```bash
npm install github:iconify/icons-solid#flag
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/flag/fr-1x1';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/flag/de-1x1';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
