Browse all icons: [preview SidekickIcons on Iconify](https://icon-sets.iconify.design/sidekickicons/)

## Installation

```bash
npm install github:iconify/icons-solid#sidekickicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/sidekickicons/crown';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/sidekickicons/blockquote';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/sidekickicons/compass';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
