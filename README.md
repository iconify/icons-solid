## Installation

```bash
npm install gitlab:iconify-icons/solid#codicon
```

or
```bash
npm install github:iconify/icons-solid#codicon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/codicon/account';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/codicon/bell-dot';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/codicon/new-file';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
