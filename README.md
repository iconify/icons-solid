Browse all icons: **[Preview Fluent UI System Color Icons](https://icon-sets.iconify.design/fluent-color/)**

## Installation

```bash
npm install github:iconify/icons-solid#fluent-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/fluent-color/mic-20';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/fluent-color/alert-32';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
