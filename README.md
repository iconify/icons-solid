## Installation

```bash
npm install gitlab:iconify-icons/solid#ci
```

or
```bash
npm install github:iconify/icons-solid#ci
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/ci/bulb';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/ci/house-01';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/ci/compass';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
