## Installation

```bash
npm install github:iconify/icons-solid#eos-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/eos-icons/modified-date-outlined';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/eos-icons/arrow-rotate';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/eos-icons/package';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
