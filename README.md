Browse all icons: [preview Line Awesome on Iconify](https://icon-sets.iconify.design/la/)

## Installation

```bash
npm install github:iconify/icons-solid#la
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/la/archive-solid';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/la/female-solid';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/la/check-circle';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
