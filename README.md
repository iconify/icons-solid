## Installation

```bash
npm install github:iconify/icons-solid#streamline-logos
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/streamline-logos/microsoft-windows-logo-2';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/streamline-logos/unspash-logo-solid';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/streamline-logos/patreon-logo';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
