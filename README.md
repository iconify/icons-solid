Author: [Automattic](https://github.com/Automattic/gridicons)

License: [GPL 2.0](https://github.com/Automattic/gridicons/blob/trunk/LICENSE.md)

Browse all icons: [preview Gridicons on Iconify](https://icon-sets.iconify.design/gridicons/)

## Installation

```bash
npm install github:iconify/icons-solid#gridicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/gridicons/code';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/gridicons/multiple-users';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/gridicons/types';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
