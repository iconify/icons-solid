# @iconify-solid/meteocons

**Meteocons**

Author: [Bas Milius](https://github.com/basmilius/weather-icons)

License: [MIT](https://github.com/basmilius/weather-icons/blob/dev/LICENSE)

Browse all icons: [preview Meteocons on Iconify](https://icon-sets.iconify.design/meteocons/)

## Installation

```bash
npm install github:iconify/icons-solid#meteocons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/meteocons/hurricane-fill';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/meteocons/sunrise-fill';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
