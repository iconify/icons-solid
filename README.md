## Installation

```bash
npm install github:iconify/icons-solid#streamline-cyber
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/streamline-cyber/music-note-1';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/streamline-cyber/navigation-up-arrow';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/streamline-cyber/map-direction';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
