## Installation

```bash
npm install github:iconify/icons-solid#bytesize
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/bytesize/desktop';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/bytesize/code';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/bytesize/sign-out';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
