## Installation

```bash
npm install github:iconify/icons-solid#eva
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/eva/droplet-off-outline';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/eva/flash-fill';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/eva/printer-outline';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
