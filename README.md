Browse all icons: [preview Pullo Icons on Iconify](https://icon-sets.iconify.design/pullo/)

## Installation

```bash
npm install gitlab:iconify-icons/solid#pullo
```

or
```bash
npm install github:iconify/icons-solid#pullo
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/pullo/file-check';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/pullo/turtle-fill';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/pullo/chart-area-duotone';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
