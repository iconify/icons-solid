Browse all icons: [preview Material Design Light on Iconify](https://icon-sets.iconify.design/mdi-light/)

## Installation

```bash
npm install github:iconify/icons-solid#mdi-light
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/mdi-light/cart';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/mdi-light/bell';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/mdi-light/login';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
