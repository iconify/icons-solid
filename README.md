Browse all icons: [preview with icons Chrome on Iconify](https://icon-sets.iconify.design/withicons-chrome/)

## Installation

```bash
npm install gitlab:iconify-icons/solid#withicons-chrome
```

or
```bash
npm install github:iconify/icons-solid#withicons-chrome
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/withicons-chrome/home';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/withicons-chrome/search';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
