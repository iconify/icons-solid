```bash

```

or
```bash
npm install github:iconify/icons-solid#cbi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/cbi/mitsubishi';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/cbi/espn';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/cbi/rooms-computer';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
