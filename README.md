## Installation

```bash
npm install github:iconify/icons-solid#catppuccin
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/catppuccin/folder';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/catppuccin/nuxt';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
