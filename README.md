License: [MIT](https://github.com/codex-team/icons/blob/master/LICENSE)

Browse all icons: [preview CodeX Icons on Iconify](https://icon-sets.iconify.design/codex/)

## Installation

```bash
npm install gitlab:iconify-icons/solid#codex
```

or
```bash
npm install github:iconify/icons-solid#codex
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/codex/align-left';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/codex/table-with-headings';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/codex/heading';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
