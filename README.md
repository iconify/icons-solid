Browse all icons: [preview Streamline Emojis on Iconify](https://icon-sets.iconify.design/streamline-emojis/)

## Installation

```bash
npm install github:iconify/icons-solid#streamline-emojis
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/streamline-emojis/crescent-moon';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/streamline-emojis/fire';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
