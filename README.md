## Installation

```bash
npm install github:iconify/icons-solid#zmdi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/zmdi/alarm-snooze';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/zmdi/cloud-off';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/zmdi/library';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
