**Phosphor**

Author: [Phosphor Icons](https://github.com/phosphor-icons/core)

License: [MIT](https://github.com/phosphor-icons/core/blob/main/LICENSE)

Browse all icons: [preview Phosphor on Iconify](https://icon-sets.iconify.design/ph/)

## Installation

```bash
npm install github:iconify/icons-solid#ph
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/ph/folder-open-duotone';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/ph/check-square-offset-thin';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/ph/pencil-line-fill';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
