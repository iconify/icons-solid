Browse all icons: [preview IconMind on Iconify](https://icon-sets.iconify.design/iconmind/)

## Installation

```bash
npm install github:iconify/icons-solid#iconmind
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/iconmind/agent-outline-regular';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/iconmind/vector-database-duotone-thin';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/iconmind/stub-tool-outline-bold';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
