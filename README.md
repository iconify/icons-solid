Browse all icons: [preview Humbleicons on Iconify](https://icon-sets.iconify.design/humbleicons/)

## Installation

```bash
npm install github:iconify/icons-solid#humbleicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/humbleicons/aid';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/humbleicons/droplet';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/humbleicons/rss';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
