Browse all icons: [preview Lineicons on Iconify](https://icon-sets.iconify.design/lineicons/)

## Installation

```bash
npm install github:iconify/icons-solid#lineicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/lineicons/check';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/lineicons/vuejs';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/lineicons/star-fat';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
