Icon set prefix: **fxemoji**

Icon set name: **Firefox OS Emoji**

Author: **Mozilla**

License: **[Apache 2.0](https://mozilla.github.io/fxemoji/LICENSE.md)**

Repository: **https://github.com/mozilla/fxemoji**

Browse all icons: **[Preview Firefox OS Emoji](https://icon-sets.iconify.design/fxemoji/)**

## Installation

```bash
npm install github:iconify/icons-solid#fxemoji
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/fxemoji/foxweary';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/fxemoji/loveletter';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
