Browse all icons: [preview HeroIcons v1 Solid on Iconify](https://icon-sets.iconify.design/heroicons-solid/)

## Installation

```bash
npm install github:iconify/icons-solid#heroicons-solid
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/heroicons-solid/color-swatch';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/heroicons-solid/library';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/heroicons-solid/receipt-refund';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
