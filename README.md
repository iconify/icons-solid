**HeroIcons**

Author: [Refactoring UI Inc](https://github.com/tailwindlabs/heroicons)

License: [MIT](https://github.com/tailwindlabs/heroicons/blob/master/LICENSE)

Browse all icons: [preview HeroIcons on Iconify](https://icon-sets.iconify.design/heroicons/)

## Installation

```bash
npm install github:iconify/icons-solid#heroicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/heroicons/camera';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/heroicons/building-library';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/heroicons/receipt-refund';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
