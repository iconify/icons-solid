**Huge Icons**

Author: [Hugeicons](https://icon-sets.iconify.design/icon-sets/hugeicons/)

License: MIT

Browse all icons: [preview Huge Icons on Iconify](https://icon-sets.iconify.design/hugeicons/)

## Installation

```bash
npm install github:iconify/icons-solid#hugeicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/hugeicons/analytics-up';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/hugeicons/android';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/hugeicons/search-02';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
