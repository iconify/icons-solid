Browse all icons: **[Preview Foundation](https://icon-sets.iconify.design/foundation/)**

## Installation

```bash
npm install github:iconify/icons-solid#foundation
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/foundation/graph-trend';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/foundation/indent-more';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/foundation/lock';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
