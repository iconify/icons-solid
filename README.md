## Installation

```bash
npm install gitlab:iconify-icons/solid#gis
```

or
```bash
npm install github:iconify/icons-solid#gis
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/gis/layer-o';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/gis/poi-o';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/gis/bbox';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
