## Installation

```bash
npm install github:iconify/icons-solid#topcoat
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/topcoat/wifi';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/topcoat/feedback';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/topcoat/pencil';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
