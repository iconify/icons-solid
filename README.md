Browse all icons: [preview Teenyicons on Iconify](https://icon-sets.iconify.design/teenyicons/)

## Installation

```bash
npm install github:iconify/icons-solid#teenyicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/teenyicons/face-id-solid';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/teenyicons/user-outline';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/teenyicons/page-break-outline';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
