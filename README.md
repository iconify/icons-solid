Browse all icons: [preview Zondicons on Iconify](https://icon-sets.iconify.design/zondicons/)

## Installation

```bash
npm install github:iconify/icons-solid#zondicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/zondicons/copy';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/zondicons/hand-stop';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/zondicons/mouse';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
