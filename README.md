## Installation

```bash
npm install github:iconify/icons-solid#devicon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/devicon/windows8';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/devicon/tensorflow';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
