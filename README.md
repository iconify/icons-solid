Author: [Wis Design](https://www.lsicon.com/)

License: [MIT](https://github.com/wisdesignsystem/lsicon/blob/main/LICENSE)

Browse all icons: [preview Lsicon on Iconify](https://icon-sets.iconify.design/lsicon/)

## Installation

```bash
npm install github:iconify/icons-solid#lsicon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/lsicon/pointer-outline';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/lsicon/column-filled';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/lsicon/vip-outline';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
