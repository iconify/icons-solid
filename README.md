**Iconaut**

Author: [Iconaut](https://github.com/iconaut-design/icons)

License: [MIT](https://github.com/iconaut-design/icons/blob/main/LICENSE)

Browse all icons: [preview Iconaut on Iconify](https://icon-sets.iconify.design/iconaut/)

## Installation

```bash
npm install gitlab:iconify-icons/solid#iconaut
```

or
```bash
npm install github:iconify/icons-solid#iconaut
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/iconaut/award-duo';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/iconaut/play';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/iconaut/bookmark-duo';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
