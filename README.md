## Installation

```bash
npm install gitlab:iconify-icons/solid#selfhst
```

or
```bash
npm install github:iconify/icons-solid#selfhst
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/selfhst/salt';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/selfhst/adobe';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
