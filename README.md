Browse all icons: [preview SVG Spinners on Iconify](https://icon-sets.iconify.design/svg-spinners/)

## Installation

```bash
npm install github:iconify/icons-solid#svg-spinners
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/svg-spinners/tadpole';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/svg-spinners/pulse';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/svg-spinners/3-dots-rotate';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
