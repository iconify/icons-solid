## Installation

```bash
npm install github:iconify/icons-solid#vadivam
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/vadivam/axis-3d';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/vadivam/flag';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/vadivam/app-window-mac';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
