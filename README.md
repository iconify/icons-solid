## Installation

```bash
npm install gitlab:iconify-icons/solid#material-symbols
```

or
```bash
npm install github:iconify/icons-solid#material-symbols
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/material-symbols/downloading';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/material-symbols/privacy-tip';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/material-symbols/filter-drama-outline';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
