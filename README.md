## Installation

```bash
npm install gitlab:iconify-icons/solid#uix-sharp
```

or
```bash
npm install github:iconify/icons-solid#uix-sharp
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/uix-sharp/account-code';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/uix-sharp/electricity';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/uix-sharp/dore-bar';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
