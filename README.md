Browse all icons: [preview Remix Icon on Iconify](https://icon-sets.iconify.design/ri/)

## Installation

```bash
npm install github:iconify/icons-solid#ri
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/ri/lock-2-line';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/ri/mark-pen-fill';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/ri/moon-line';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
