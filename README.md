Browse all icons: [preview EVicons on Iconify](https://icon-sets.iconify.design/evicons/)

## Installation

```bash
npm install gitlab:iconify-icons/solid#evicons
```

or
```bash
npm install github:iconify/icons-solid#evicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/evicons/marker-queue';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/evicons/driving-range';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/evicons/plug-in-hybrid';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
