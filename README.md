Browse all icons: [preview Siemens Industrial Experience Icons on Iconify](https://icon-sets.iconify.design/ix/)

## Installation

```bash
npm install github:iconify/icons-solid#ix
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/ix/notification-filled';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/ix/home-filled';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/ix/panel-ipc';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
