## Installation

```bash
npm install gitlab:iconify-icons/solid#keyline-icons
```

or
```bash
npm install github:iconify/icons-solid#keyline-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/solid/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-solid/keyline-icons/arrow-up-narrow-wide-duotone';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-solid/keyline-icons/credit-card-fill';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-solid/keyline-icons/upload';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
